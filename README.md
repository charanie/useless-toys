## 技术

- 纯 **HTML + CSS + 原生 JavaScript**，零依赖、零构建、零网络请求
- 音效全部用 **Web Audio API 程序化合成**——仓库里没有任何音频文件
- 图形用 **Canvas 2D** 实时绘制
- 自适应桌面 / 移动端

## 本地打开

直接双击 `index.html` 即可；或起一个静态服务：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```
