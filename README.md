# 抽象玩具铺 · Useless Toys

四件**毫无用途**、但会让人停不下来的小东西。全部是**零依赖的单文件网页**，双击即开，不联网也能跑。

> ⚠ 本铺所有商品均无任何用途，打开即视为自愿。

## 技术

- 纯 HTML + CSS + 原生 JavaScript，**零依赖、零构建、零网络请求**
- 音效全部用 **Web Audio API 程序化合成**（没有音频素材文件）
- 图形用 **Canvas 2D** 实时绘制
- 自适应桌面 / 移动端

## 本地打开

```bash
# 直接双击 index.html 即可；或起个静态服务
python -m http.server 8000
# 然后访问 http://localhost:8000
```
