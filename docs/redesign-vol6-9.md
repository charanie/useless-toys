# 抽象玩具铺 · VOL.6–9 重做设计记录

> 2026-10-14。起因：用户反馈「最开始的那些小游戏很有创意，后面的有点太普通了」。
> 本文是 19 件的设计基准，分批执行期间逐件对照。**网址目录名一律不动，只改显示名与机制。**

## 诊断

VOL.1–5 的命名第二个词是「它自己是什么」或「它干了什么」（无限加载 / 打字砖 / **会记仇的**计算器 / 赛博求签机）；
VOL.6–9 里 **16/19 件**的第二个词是**品类名**（打砖块 / 扫雷 / 推箱子 / 太鼓 / 钓鱼 / 华容道 / 合成）。
名字没起错——它们确实就是「经典玩法 + 打工人皮肤」，撕掉皮肤就是原版。

前段每件都有个**只有它才成立的反直觉规则**（取消键会跑 / 攒够次数会罢工 / 功德越高界面越失控 / 消掉一行会读成一句话）。
后段的笑点贴在皮上，不在骨头上：规则可以换成任何题材，题材也可以换成任何规则。

## 设计原则

**笑点必须是机制本身。** 判据：这条规则能不能整段搬到别的题材上？能，就是皮肤；不能，才是机制。
命名判据：名字是**有画面的具体事物或动作**，不是品类标签。（偷自 GitHub 同类合集：是「节拍饭团：夜市巡演」，不是「音乐游戏」。）

## 19 件提案

| 目录 | 现在 | 改成 | 机制 |
| --- | --- | --- | --- |
| cyber-2048 | 抽象 2048 | **向上管理** | 每合成出一个新等级，棋盘空降一块「领导」障碍；两块领导相邻会互相甩锅、双双消失。越强，领导越多 |
| cyber-snake | KPI 贪吃蛇 | **今日汇报** | 给出目标汇报句，KPI 上各写一个字，按顺序吃对才拼成句子；吃错字身上留错别字 |
| cyber-breakout | 抽象打砖块 | **擦屁股** | 打碎的砖变成「锅」往下掉，要用挡板接住——打完得自己收拾 |
| cyber-mines | 抽象扫雷 | **救火** | 踩雷不是立刻死，是被拉进会议：限时把周围的雷全插旗才能脱身 |
| cyber-sokoban | 抽象推箱子 | **排期** | 每关步数有限=工期，超了算「延期」；连撤销都吃步数 |
| cyber-mole | 抽象打地鼠 | **摸鱼** | 角色反转：你才是那只鼠。探头吃外卖，领导看过来必须缩回去 |
| cyber-jump | 一键跳 KPI | **跳槽** | 平台是公司：有的是皮包公司（踩上去直接塌），每个平台都会慢慢下沉；落点准=谈薪成功 |
| cyber-gomoku | 五子棋 vs 杠精 | **杠精棋** | 杠精会改规则：五连它说「这次算四连」，会「我补充一句」连下两手，还会悔棋 |
| cyber-keys | 抽象落键 | **多线程** | 四轨=四个线程，中途线程被占用/中断；长按条的头部永远看不到（会议没有结束时间） |
| cyber-taiko | 抽象太鼓 | **复议** | 红蓝=同意/反对，中途含义互换（「换了个说法」） |
| cyber-tap | 抽象点音 | **画饼** | 有些圈是领导画的虚饼，点了就扣分——但越到后面虚饼越像真的 |
| cyber-beatrun | 抽象节奏跑 | **末班车** | 障碍是「临时加塞」和「需求变更」，踩错拍就赶不上车 |
| cyber-memory | 抽象记忆 | **需求变更** | 每配对成功一对，剩下的牌全部重新洗牌 |
| cyber-slide | 抽象华容道 | **拼脸** | 目标不是排数字，是拼出一张打工人表情包；有一块是「领导工位」不能动 |
| cyber-catch | 抽象接住 | **甩锅** | 反过来：锅追着你跑，拖鼠标把锅甩给同事，甩不掉自己背 |
| cyber-fish | 抽象钓鱼 | **抢功** | 池子里还有个同事在钓，同一根鱼线两人抢；拉慢了弹「XXX 抢了你的功劳」 |
| cyber-stack | 抽象叠塔 | **架构** | 已叠好的下层会随时间左右漂移（组织架构调整），得在晃动的基座上对齐 |
| cyber-hook | 抽象挖矿 | **返工** | 东西拉回来半路会反悔——「这个需求我做不了」，越重越容易脱钩掉回去 |
| cyber-merge | 抽象合成 | **重组** | 重力方向随「公司战略」定期倾斜，球全往一边堆 |

### VOL.8 追加的跨四件主机制

音乐是现场合成的，所以：**你打得怎么样，歌就长什么样。**
连击高 → 加入新声部、和弦变亮、鼓点变密；失误 → 掉声部、走音、变调、鼓点变稀。是「演奏」，不是「打谱」。
只有「音乐是算出来的」做得到。
